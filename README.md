# Student Management System

A full-stack Student Management System built using Spring Boot and React.

## Technologies Used

- Java
- Spring Boot
- Spring Security
- JWT
- MySQL
- React.js
- JavaScript
- REST API
- Axios
- Tailwind CSS

## Features

- Student management
- Course management
- REST APIs
- JWT-based authentication
- Role-based access
- Form validation
- Exception handling
- React frontend

## Project Structure

- `backend` – Spring Boot backend
- `frontend` – React frontend
